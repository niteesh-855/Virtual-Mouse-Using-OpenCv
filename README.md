# Virtual Mouse Using OpenCV and MediaPipe

## Overview
This project implements a Virtual Mouse using **OpenCV and MediaPipe**. It enables users to control the mouse cursor with hand gestures, eliminating the need for a physical mouse. The cursor moves continuously based on the index finger's position.

## Features
- Hand Tracking with MediaPipe
- Cursor Movement using Index Finger
- Click Actions with Finger Gestures
- Scrolling using Hand Movements
- Real-time Gesture Recognition

## Technologies Used
- Python
- OpenCV (for image processing)
- MediaPipe (for hand tracking)
- PyAutoGUI (for mouse control)
- NumPy

## How to Use
1. Move Cursor: Move your **index finger** to control the cursor.
2. Click: Touch the **thumb and index finger** together to simulate a click.
3. Scroll: Move your hand **up or down** to scroll.
4. Exit: Press `Q` to quit the application.

## Future Enhancements

- Improve accuracy and reduce latency.
- Implement right-click and drag functionalities.
